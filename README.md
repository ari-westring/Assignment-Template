# Introduction
This is an assignment template for TU Dublin students, it includes a cover sheet based on the one used in Aviation Technology (TU721).

This template is primarily intended for Aviation Tech. students and may not follow guidelines for other courses.

# Features
- Aviation Technology cover sheet with easy to use fields
- Harvard referencing style according to "Cite Them Right"
- Table of contents and page numbers set up for assignment guidelines

# Usage
1. Download TU Dublin logo from the official branding toolkit: https://www.tudublin.ie/explore/our-brand/
2. Add ```TUDublin_Colour_RGB.svg``` to the project
3. Replace all variables for the cover sheet fields
4. Delete the examples and get writing!
